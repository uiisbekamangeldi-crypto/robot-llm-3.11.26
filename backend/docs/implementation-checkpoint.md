Все документы остались `pending_review` и `internal`.
- P4: 1888 embeddings по multilingual MiniLM (384 измерения), поиск pgvector с фильтрами доступа и порогом релевантности. Пробные поиски на KK/RU/EN по внутреннему индексу возвратили фрагменты; публичный индекс пуст до документального одобрения.

- P6: Faster Whisper small, WAV-валидация, ресемплинг до 16 кГц, VAD, KK/RU/EN language hint, timeout, ленивое создание модели. Синтетические WAV распознаны: EN и RU точно для выбранных коротких фраз, KK с орфографическими ошибками. На синтетическом вопросе «Кто ректор университета?» RU STT ошибся: «то реактор университета».
- P7: Piper с зарегистрированными голосами `en_US-lessac-medium`, `ru_RU-irina-medium`, `kk_KZ-issai-high`; все три синтезировали корректный WAV. Качество казахского голоса на живой речи не оценено.
- P8: текстовый и аудио API, локальный сквозной прогон WAV → STT → RAG → ответ без подтверждения → TTS → WAV. Сессии, turn/request ID, PostgreSQL persistence, idempotency key и latency в БД. Проверка дубля вернула прежние ID. При отсутствии одобренных документов API не выдаёт университетский факт.
- P9: отдельный mock RobotAudioAgent с robot ID, HTTP WAV transport, API key, timeout и контрактным тестом. Unitree SDK не используется.
- P11 частично: структурированные логи, readiness, ключ API для диалоговых маршрутов, лимит 60 запросов в минуту через Redis, валидация, ручная очистка старых диалогов (`scripts/prune_dialogs.py`, dry run по умолчанию).
- Проверки: `ruff check .`, `mypy app`, `pytest -q`: 20 tests passed. Реальные локальные PostgreSQL, Redis, MinIO, pgvector и модель проверялись отдельно. Проверка полного Docker Compose продолжается.
